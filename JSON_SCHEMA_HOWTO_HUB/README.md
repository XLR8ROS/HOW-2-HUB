# JSON Schema HOW-TO HUB

Markdown and JSON documentation pulled from official JSON Schema sources.

## Contents

- `docs/00_json_schema_site/markdown/` — official JSON Schema site pages converted to Markdown.
- `docs/01_json_schema_spec_repo/markdown/` — source/reference files from the official `json-schema-org/json-schema-spec` repo.
- `docs/02_json_schema_test_suite/markdown/` — conformance tests and docs from the official JSON Schema Test Suite repo.
- `docs/03_meta_schemas/markdown/` — official 2020-12 meta-schemas and output schema.

## Boundary

This hub contains documentation only. It does not create SOP files, backlog files, task files, or Codi queue files.
