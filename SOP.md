## QMD Hub Handling

QMD is handled under the general HOW-2-HUB SOP.

QMD does not get a separate standalone SOP by default. The general HOW-2-HUB SOP governs how QMD documentation is sourced, structured, verified, updated, committed, and maintained.

For the QMD Hub, apply the standard hub workflow with these QMD-specific requirements:

- Use source-backed documentation from live QMD CLI/help output and current XOS canon where applicable.
- Keep a clear distinction between QMD as a retrieval/indexing layer and durable memory as the source of truth.
- Verify command examples against the installed QMD syntax before treating them as usable instructions.
- Cover query, sync, watcher, index, collection, and retrieval troubleshooting.
- Keep QMD placement inside HOW-2-HUB as a hub entry, not as a separate SOP system.
- Make no repo-specific operational changes unless the task explicitly calls for them.
